# SaveTask-SRF

## frontend

Uses Next.js with tailwind

- Show a simple form with Name, Date and Add button
- Show a simple list with list of pending items
- Within the list, show a button with Done button
- Show a small list with recently completed Items

## Backend

To setup, add these in the vscode settings incase if the go version was not installed in windows

```json
"go.goroot": "C:/Users/<USER>/Documents/go",
"terminal.integrated.env.windows": {
    "GOROOT": "C:/Users/<USER>/Documents/go",
    "GOPATH": "C:/Users/<USER>/Documents/go",
    "PATH": "C:/Users/<USER>/Documents/go/bin;${env:PATH}"
}
```

Use Golang with Gin

- An API for storing user data
- Another API for storing tasks

## Database

User-api: use postgres
Task-api: use mongo
